TouchBistro is an iPad-based restaurant point-of-sale (POS) and management platform covering payments, online ordering, reservations, loyalty, gift cards, marketing, inventory, labor, and reporting. TouchBistro does not publish an open, self-serve developer API or a public developer portal; it exposes a private, partner-only integration API. The CEO has publicly confirmed an API exists but is not openly promoted. Third-party software providers must apply to the integration partner program, be approved, and are issued monitored API keys under negotiated commercial terms (contact integratedpartners@touchbistro.com).

## Features

| Name | Description |
|------|-------------|
| Point of Sale | Cloud-based iPad POS that is the core engine of restaurant operations. |
| Payment Processing | TouchBistro Payments plus integrated processing via Chase, Worldpay, and Moneris. |
| Tableside Ordering | Mobile POS for capturing orders, upsells, and split checks at the table. |
| Kitchen Display System | Connects front and back of house for timely order fulfillment. |
| Online Ordering | Direct online ordering through the restaurant's own channels. |
| Reservations | Capacity management, waitlists, and VIP guest handling. |
| Loyalty and Gift Cards | Rewards program and modern digital gift cards to drive repeat business. |
| Marketing | Automated, data-driven guest marketing campaigns. |
| Inventory Management | Stock tracking to minimize waste and reduce food costs. |
| Labor Management | Staff scheduling and payroll cost monitoring. |
| Reporting and Analytics | Cloud reports accessible remotely for data-driven decisions. |
| Menu and Floor Plan Management | Build menus and design floor layouts, sections, and table status. |
